Many alerts, one cause. The graph finds it.

rootgraph walks a FalkorDB graph of your infrastructure upward from the symptoms, proves the cause with the network path and the change behind it, and proposes a fix a human approves. The graph decides, the agent explains, a human acts.

Sandbox: a synthetic estate. Scenarios replay recorded faults; approving a fix only changes the graph.
